# Reservation frontend

Тестовый интерфейс для Spring Boot API бронирования кинотеатра.

```bash
npm install
npm run dev
```

Сначала запустите backend на `http://localhost:8080`. Dev-сервер доступен на `http://localhost:5173` и проксирует API-запросы на backend.

Для production/preview скопируйте `.env.example` в `.env` и укажите адрес API в `VITE_API_URL`.
